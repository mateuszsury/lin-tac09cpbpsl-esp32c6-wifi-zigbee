# Code of conduct

## Our standard

Project discussions should be technical, respectful and safe. Contributors are
expected to:

- focus criticism on code, measurements and reproducible behavior;
- distinguish verified observations from interpretation;
- protect credentials, household data and identifying information;
- respect different levels of hardware and embedded-systems experience;
- stop unsafe electrical testing instead of pressuring someone to continue.

Harassment, discriminatory language, threats, deliberate publication of private
data and knowingly unsafe instructions are not accepted.

## Enforcement

Report conduct problems privately through the repository's security advisory
form. Maintainers may edit or remove content, close discussions, reject
contributions or restrict participation when needed to protect contributors and
the project.

## Scope

This code of conduct applies to repository issues, pull requests, discussions
and other spaces where someone represents the project.
