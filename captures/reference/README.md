# Curated protocol captures

This directory contains only small, action-labelled and redacted evidence used
by `docs/PROTOCOL.md`:

- `protocol-baseline-20260812.txt` - framing and stable state examples;
- `remote-button-sequence-20260812.txt` - ordered Power/Temperature/Fan/Mode actions;
- `isolated-features-20260812.txt` - Quiet, units and Timer correlations.

Raw captures belong in ignored `captures/tmp/`. Before contributing a capture,
remove credentials, host names, IP addresses, personal device names and
unrelated Home Assistant data.
